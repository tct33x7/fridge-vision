# 手持拍摄枪 V1

这是根据实物照片和现有量测制作的第一版参数化结构。目标是先验证：

- 单手握持是否自然；
- 摄像头能否牢固安装并对准小票；
- 微动开关能否在食指位置触发；
- 两组线束能否沿手柄走线，并从底部引出。

## 当前结构

- 摄像头面板安装在枪头朝前的外表面，四个 M3 螺丝孔直接对准面板孔位；
- 微动开关 PCB 安装在握把前侧、食指自然能够按到的位置；面板正面朝前，金属拨杆向下作为简易扳机；
- 两个面板各有独立小进线槽，线束进入空心手柄后从底部共同引出；
- 枪体分为前壳和后壳，便于装入摄像头、按钮及线束；
- 前后壳使用 4 颗 M3 长螺丝固定：螺丝从后壳进入，拧入前壳的热熔螺母；
- 手柄底部具有 10 mm 出线孔；
- 手柄后下方有两条扎带槽，用作第一版防拉扯结构；
- 摄像头与按钮使用 M3、外径 3.9 mm、长度 2.85 mm 的热熔螺母。

前后壳螺丝长度需要在打印后根据实际壳体和螺丝头形式确认，预计从 M3×20 左右开始试配，不要在未量测前批量购买。

## 打开与导出

1. 使用 OpenSCAD 打开 `scanner_gun_v1.scad`。
2. 修改文件顶部的 `part`：
   - `"assembly"`：查看整机；
   - `"exploded"`：查看爆炸结构；
   - `"front_shell"`：导出前壳；
   - `"rear_shell"`：导出后壳；
   - `"camera_test"`：导出摄像头安装测试片。
3. 按 F6 完整渲染，再导出 STL。

## 推荐打印顺序

1. 先打印 `camera_test`，不要直接打印整枪。
2. 将四个 M3 热熔螺母压入测试片，检查是否松动或导致塑料开裂。
3. 用摄像头 PCB 检查四个螺丝位置与热熔螺母配合。
4. 测试通过后再打印前壳与后壳。

建议初次使用 PETG、0.4 mm 喷嘴、0.2 mm 层高、4 道墙。测试片中的热熔孔默认直径为 3.70 mm；如果过紧或过松，每次调整 0.10 mm。

## 第一版仍需实物确认

照片无法可靠提供以下尺寸，因此模型采用了可修改的估计值：

- 摄像头孔中心距：暂定 30.8 × 30.8 mm；
- 按钮 PCB 孔中心距：暂定 24 × 24 mm；
- 微动开关的准确拨杆位置与运动行程。

这些参数都集中放在 SCAD 文件顶部。第一版的重点是验证空间与握持，不应直接作为最终生产文件。

## 线缆方案

摄像头 USB 线和按钮信号线分别保留原始线束，在手柄内部并行走线，从底部共同引出。外部建议使用编织套管将两束线合并；不要在第一版内部增加 USB Hub，否则会增加枪体重量、发热和维修难度。
