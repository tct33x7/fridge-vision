# hardware · v4 的实物部分

v4（[ARCHITECTURE](../docs/ARCHITECTURE.md)）要做的硬件放在这里。旧项目的手持扫码枪外壳在 [archive/hardware/](../archive/hardware/)，不再使用，
但其中的建模流程（OpenSCAD / Fusion 360 → STL → 打印）可以照搬。

这一块由项目成员动手完成：设计、打印、安装，并给每一版拍照留档。

## 计划的子目录

| 目录 | 是什么 | 状态 | 前提 |
| --- | --- | --- | --- |
| `camera-mount/` | 门洞上方的相机支架：卡在上方柜体边沿，倾角 0–30° 可调，走线槽 | 待做 | E02 用手机选定机位后再设计 |
| `door-sensor/` | 干簧管门磁的安装位置和接线（→ OrangePi 40 针） | 待做 | 确定用门磁（机构有，或者自己买） |
| `host/` | OrangePi 外壳 / 安放位置；可选门边小屏支架 | 待做 | 确定主机放哪、要不要小屏 |

每个子目录建议放：源文件（`.scad` / `.f3d` / `.step`）、导出件（`.stl` / `.3mf`）、实物照片、`README.md`（尺寸、打印参数、装配步骤、改了几版）。
