## 约定

- **文件名**：`E编号_英文短名_日期.md`，例如 `E04_overhead_20261114.md`。
- **原始数据**：`fridge_vision/runs/e编号_短名_日期/`（录像、关键帧、`session.json`、`summary.md`、人工表），**永不进 git**。
  录制时加 `--out-dir` 指定，例如：

```bash
SOURCE=0 ~/Projects/bx-project/fridge_vision/run_record.command --trigger manual --out-dir runs/e03_overhead_20261114
```

- **每个记录写清**：目的、装置（相机、位置、触发、参数）、过程、结果（附命令，能重跑）、真值质量、观察、局限、对设计的影响。
- **谁写的要分清**：脚本算出的数字、Claude 的观察、你的观察分开写。你的观察那一节只由你写。
- 报告要用的图挑好、确认没有人脸后，放进 [docs/report/figures/](../report/)。
