### 6. 11-08 中午到下午：7 步计划，改计数规则（E02）

发生了什么：

- 项目发起人和老师列了 7 步待办流程（[日程](SCHEDULE.md)）：电脑端初步计数 → 光线和抖动优化 → 待机和自启动 → 复杂情况测试 → OCR 区分饮料 → 部署到板子 → 冰箱实机测试。
- 第 1 步是老师做的网页计数 demo（YOLO11s + ByteTrack，在画面上拖一条线，按方向计数），11:41 收进仓库（提交 `3f1316a`；作者一栏根目录 README 写的是"请老师确认"）。
- 第 2 步：项目发起人照着动作清单在桌面上录了 3 段测试视频（抖动、光线、复杂情况），Claude 写了重放工具，同一段录像上比较新旧计数规则。
- **"只看最后"这条规则是项目发起人选的**：Claude 问"拿出又马上放回、晃动时整个过了线，算不算进出"，给了"算，按实际过线"和"不算，只看最后"两个选项，他选了后一个。所以东西拿出去又马上放回来、在线上晃，都不算，只看它最后停在哪一边（提交 `7cf09a0`）。
- 结果：3 段桌面实拍共 11 次真实进出，多计 12 → 0，漏计 5 → 2。这是**开发集**上的数字：规则是在这几段录像上调出来、又在这几段上测的，会偏乐观（核对表第 3 行）。
