# 家用纯视觉冰箱记账系统 · 项目计划书

版本 1.0　|　2026-11-06　|　仓库 `~/Projects/bx-project`

## 1. 项目概述

**一句话**：在冰箱门口装一个摄像头，开门时自动看清手里放进去、拿出来的是什么，不用拍照、不用扫码、不用输入，
手机上随时知道冰箱里有什么、什么快过期、今天吃什么。

**背景**：项目前身"饮食均衡助手"已经做出两套可运行软件（手机上传式识别 demo、本地优先库存后端）和一把扫码枪壳体，
但都要求用户主动拍照或扫码。实际使用中"多一步"就会不用。本计划把交互压缩为零：开门即记账。

**目标**：两周内在家里跑通并连续使用；之后用一台独立的 Jetson Nano 替代开发用的 Mac，做成常开的家用设备。

## 2. 用户与场景

- 使用者：家里所有人，不需要学习，照常开冰箱放东西。
- 查看者：主要是采购和做饭的人，手机打开局域网网页看库存、临期、推荐。
- 场景 A：买菜回来往冰箱里放，系统自动记录每样食材和入库时间，按类别估到期日。
- 场景 B：拿出来吃掉或用掉，系统自动扣减。
- 场景 C：认错了，手机上"刚才的变化"里一键撤销或改数量。

## 3. 方案与架构

```text
门口摄像头（Moertek 2.4G → USB 接收器）
        │ 视频流
        ▼
主机（第一、二步：Mac；第三步：Jetson Nano 4GB）
  ├─ 开门检测    画面亮度跳变（冰箱灯亮）；可选门磁开关兜底
  ├─ 目标追踪    YOLO11n 检测 + ByteTrack 轨迹
  ├─ 过线判定    轨迹穿过门口虚拟线：进 = 放入，出 = 拿出，一条轨迹只记一次
  ├─ 关键帧      轨迹置信度最高的一帧裁图作证据；可选发大模型 API 确认名字和数量
  ├─ 库存后端    smart_fridge_app（FastAPI + SQLite）：商品、批次、流水、撤销、备份
  └─ 手机网页    局域网 :8000，首页"刚才的变化 / 临期 / 库存 / 推荐"
```

设计原则：自动记账、事后撤销，而不是每次确认；所有数据留在家里，识别可选上云但默认本地；证据图可追溯。

## 4. 功能范围

**做**

1. 开门自动触发、关门自动结束一次记账会话
2. 放入 / 拿出自动写库存流水，附证据图
3. 首页"刚才的变化"卡片，撤销与改数量
4. 按类别默认保质期，临期提醒
5. 库存清单、搜索、手动修正
6. 本地规则食谱；可选 DeepSeek 文本食谱
7. 一键备份包，设备迁移还原

**不做（本期）**

- 条码、购物小票、包装日期 OCR
- 读取包装上的真实到期日（纯视觉做不到，按类别估算）
- 多用户账号、公网访问、云同步
- 冰箱内部货架盘点（只看门口进出）
- 手持扫码枪硬件

## 5. 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 检测模型 | YOLO11n：先用自训 80 类食物权重 / COCO 通用权重，后用门口关键帧微调 | n 级模型老款 Nano 跑得动；Ultralytics 自带追踪 |
| 追踪 | ByteTrack（Ultralytics 内置） | 成熟、无需训练 |
| 认名兜底 | 多模态大模型 API（OpenAI 兼容接口，默认通义千问） | 小模型管"有东西过线"，大模型管"是什么、几个" |
| 推理运行时 | Mac：PyTorch MPS；Jetson：TensorRT FP16（JetPack 4 容器） | 各平台最快路径 |
| 后端 | FastAPI + SQLite（已有，23 个测试） | 单机、零运维、事务与备份已做好 |
| 前端 | 原生 HTML/JS（已有） | 手机浏览器直接用，无需安装 |
| 主机 | 第一、二步 Mac；第三步 Jetson Nano 4GB | 先验证再换硬件，降低返工 |

## 9. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 手握住小物件，检测不到 | 漏记 | 大模型 API 兜底认名；微调加入手持样本；提示放慢动作 |
| 80 类模型不含家里常买的东西 | 认错 | M2 攒关键帧，M4 微调；类别表按你家清单重定义 |
| 一次拿多件、轨迹互相干扰 | 漏记或重复 | 调 ByteTrack 参数；允许手机上快速改数量 |
| 门口强光或冰箱灯不亮，亮度触发失效 | 漏触发 | 门磁开关兜底 |
| 老款 Jetson Nano 软件老、已停产 | 部署慢、坏了难换 | 走 JetPack 4 容器；代码保持与 Mac 完全一致，随时可换别的主机 |
| 2.4G 与家里 Wi-Fi 同频干扰 | 掉帧 | 接收器离路由器远一点；掉帧时脚本自动重连 |
| 隐私：关键帧发给大模型服务商 | 泄露厨房画面 | 默认不开 `--vlm`；只发裁剪后的物品小图 |
