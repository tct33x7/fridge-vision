# 扫码枪项目交接总结（V3）

## 1. 项目背景与目标

这是 BX Project 的“饮食均衡助手”硬件部分。用户希望制作一把手持式扫码枪，用于拍摄并识别：

- 买菜小票；
- 文字菜品清单；
- 食材名称和数量等文字信息。

摄像头通过 USB 连接到独立的香橙派主板，香橙派负责图像传输、OCR/文字识别以及后续食材数据处理。香橙派不放进枪体内部，枪体只保留摄像头、按钮、安装结构和线材通道。

用户的实际使用方式：

- 手持式；
- 单手操作；
- 目标扫描距离约 10–30 cm；
- 摄像头是定焦 USB 摄像头；
- 摄像头线缆约 80–100 cm；
- 供电/通信通过 USB 连接主板。

当前任务重点是机械外壳建模和可打印文件，不是 OCR 软件或香橙派程序。

## 2. 用户确认过的实物尺寸

### 摄像头

- 摄像头 PCB/面板外形：约 `37.75 × 37.75 mm`；
- 摄像头凸出区域（包括面板）：约 `18 mm`；
- 用户要求摄像头面板四角用螺丝固定；
- V2 摄像头孔距为 `24 × 24 mm`；
- V3 按“稍微加大”暂定为 `25 × 25 mm`，这是当前唯一由建模者作出的合理假设，后续如用户有更准确孔距应优先替换；
- V3 正面摄像头通光圆孔：直径 `13.9 mm`。

### 按钮

- 按钮 PCB/面板外形：约 `29.92 × 29.92 mm`；
- 按钮机械装置上下总长度（包括面板）：约 `5.7 mm`；
- V2/V3 按钮孔距均保持 `24 × 24 mm`；
- 按钮安装在类似手枪扳机的位置，用户要求略微上移但不能妨碍枪头放进支架；
- 用户没有提供按钮执行器的准确开口形状，因此 V3 没有擅自增加未知的按钮开口，只保留面板安装平面。

### 热熔螺母与螺丝孔

- M3 热熔螺母外径：`3.9 mm`；
- 热熔螺母长度：`2.85 mm`；
- 当前打印起始孔：直径 `3.70 mm`、深度 `3.15 mm`；
- 面板螺丝通孔：直径 `3.40 mm`；
- 螺母从壳体内部热熔安装；螺丝从面板外侧穿过面板和壳体后进入螺母；
- 面板螺丝具体长度没有确认，不能在模型中假定固定螺丝长度。

### 线材

- 目标线径约 `2.8 mm`；
- 隐藏理线槽净截面约 `6.6 × 4.4 mm`；
- 面板隐藏进线孔直径 `4.4 mm`；
- 4.4 mm 进线孔适合裸线/线材通过，不适合已经装好的 USB 插头通过；
- 如果 USB 插头和摄像头线不可拆，后续要重新设计可拆盖板或更大的线缆入口，不能只盲目放大当前孔。

## 3. 设计演变

### 最初概念

最初用户提供了“饮食均衡助手”的功能脑图，包括食材录入、拍照识别、营养评价、下一餐推荐、冰箱展示和互动装置。硬件部分后来收敛到“扫码枪”：枪上只有摄像头和按钮，香橙派与枪体分离。

### V1/V2 阶段的主要要求

早期版本曾出现摄像头/按钮模拟实体、额外开口和过多内部结构。用户随后明确要求：

- 去掉摄像头和按钮的模拟实体，只保留枪体；
- 枪头正面为摄像头面板安装位置；
- 按钮面板正向朝前，放在食指扳机区域；
- 保持左右分体式结构；
- 内部主要做结构支撑，不做复杂走线隧道；
- 之后又允许增加一个合理的隐藏理线槽，保证约 2.8 mm 线材通过；
- 删除正面左下角那个没有明确用途、且比螺丝孔更大的旧开口；
- 增加一个对称、顶部/正面开放的枪头支架，便于取放和挂机；
- 整体保持精简、对称、无装饰性冗余特征。

V2 的核心尺寸和结构：

- 枪头外包络约 `58 × 38 × 58 mm`；
- 枪头中心约 `(0, 0, 130)`；
- 摄像头中心 Z 约 `130 mm`；
- 按钮中心 Z 约 `90 mm`；
- 壳体壁厚 `2.4 mm`；
- 左右壳接缝间隙 `0.30 mm`；
- 摄像头/按钮安装面在 V2 中是较薄的外部 pad；
- V2 曾使用面板下方的圆柱形螺母柱，这正是 V3 要删除的结构；
- V2 有隐藏理线槽、壳体连接柱和独立头部支架。

### V2 文件格式问题

用户曾遇到某些打印软件/建模软件打开文件卡住。之前的处理包括：

- STL 改为二进制格式；
- 3MF 改为只包含 3MF Core 模型数据的最小兼容包；
- 对 STL/3MF 做重新导入和尺寸检查；
- 建议首次不要直接打开完整一体装配 STL。

V3 没有生成测试片，也没有生成一体打印 STL；最终打印文件只有左右壳和支架。

## 4. V3 最终设计意图

用户最新要求是“复制 V2 后做 V3”，不要修改 V2 原文件。V3 的要求是：

1. 保持左右分体式结构；
2. 不要任何测试片；
3. 摄像头四孔间距比 V2 稍大；
4. 摄像头面板安装在枪体正面更靠里的“下层/凹入平面”；
5. 枪体正面中心保留 `Ø13.9 mm` 圆形区域，让摄像头镜头穿出；
6. 摄像头热熔螺母下方删除 V2 的凸出圆柱体，让 PCB 面板能够贴紧连续平面；
7. 按钮区域采用同样的连续平面安装思路；
8. 支架继续保留，但不生成测试片。

V3 的几何解释如下：

- 枪体原有前框/外表面保留在前方；
- 摄像头和按钮的安装面向内部凹入 `1.8 mm`；
- 每个安装面改为连续的 `4.8 mm` 厚平面板；
- 4 个 M3 螺母孔直接开在平面板中，不再在孔下方添加独立圆柱 boss；
- 摄像头圆孔贯穿前框和摄像头安装板；
- 摄像头镜头从圆孔伸出，摄像头 PCB 仍由四颗螺丝压在平面安装板上；
- 按钮区域只做凹入平面和四孔，没有根据未知按钮形状擅自切开额外执行器孔。

## 7. 使用 Fusion 360 的正确流程

### 直接使用当前已生成的 STEP

1. 在 Fusion 360 中选择“文件 → 打开/上传”；
2. 导入 `fusion360/scanner_gun_v3_editable.step`；
3. 等待转换完成后保存到 Fusion 项目；
4. 在浏览器中选择对应实体；
5. 可以使用直接建模方式增加草图、切孔、拉伸、倒角、移动面等；
6. 如果需要原生 Fusion 文件，将设计保存/导出为 `.f3d`。

STEP 是可编辑的 B-Rep 实体，但不会携带 Fusion 原生的参数时间线。需要批量修改参数时，应优先改 CadQuery 源文件，再重新导出 STEP。CadQuery 官方文档支持这种 STEP 导出工作流：

https://cadquery.readthedocs.io/en/latest/importexport.html

### Fusion 原生脚本备用流程

脚本路径：

`fusion360/ScannerGunFusionBuilder/ScannerGunFusionBuilder.py`

脚本会：

- 创建新的 Fusion Design；
- 导入 `exports` 中的 V3 左壳、右壳和支架 STL；
- 尝试 Prismatic mesh conversion；
- 失败时使用 Faceted B-Rep fallback；
- 添加摄像头孔距、凹入深度、安装板厚度、圆孔等参考用户参数；
- 输出 `scanner_gun_v3_editable.f3d`；
- 输出 `scanner_gun_v3_fusion.step`。

之前已在 Fusion 中成功识别并添加过同结构的 V2 脚本，但当时 Mac 在真正运行前进入锁屏，原生 `.f3d` 没有最终生成。因此下一位 AI 若要生成 `.f3d`，必须先让用户解锁 Mac，再通过 Fusion 的 Scripts and Add-Ins 运行 V3 脚本，不能尝试绕过锁屏。

## 8. CadQuery 构建工作流与依赖注意

V3 的干净实体不是从 STL 三角网格反向转换得到，而是由 CadQuery 重新构建的 B-Rep：

1. 读取顶部精确参数；
2. 构建圆角枪头、手柄 loft、按钮支撑和中空壳体；
3. 加入凹入平面安装板；
4. 切出摄像头圆孔、面板螺丝孔、热熔螺母孔、进线孔、理线槽和左右壳连接孔；
5. 按 X=0 分割为左右壳；
6. 构建独立支架；
7. 生成 STEP、STL，并检查实体有效性。

CadQuery 2.8.0/OCP 运行库曾安装到项目中的 `vendor`，体积约 1.3 GB；验证完成后为了不污染项目，已经移动到：

## 10. 仍需用户确认或后续处理的事项

### 必须确认

1. 摄像头“稍微加大”的孔距是否接受当前假设 `25 × 25 mm`；
2. `13.9 mm` 圆孔是否以摄像头 PCB 几何中心为中心，还是应根据实际镜头中心偏移；
3. 摄像头镜头外径、镜头外壳长度和相对 PCB 的偏移是否确实能通过 `Ø13.9 mm`；
4. `1.8 mm` 凹入深度是否适合摄像头/按钮的实际凸出高度；
5. 按钮是否需要单独的执行器开口；
6. 是否要求 V3 的整体外部包络严格等于 V2，特别是 Y 方向的 1.2 mm 差异；
7. 摄像头线缆的 USB 插头是否可以拆下后穿过 `Ø4.4 mm` 入口。

### 建议下一步

1. 先在 Fusion 中导入单独的左右壳 STEP，检查凹入安装面和圆孔；
2. 让用户用真实摄像头 PCB 和按钮面板比对孔距、孔边距、面板是否贴紧；
3. 如果用户解锁 Mac，运行 Fusion V3 脚本生成原生 `.f3d`；
4. 若实际摄像头中心不是 PCB 中心，修改 `CAMERA_CENTER_X/Z` 或对应圆孔位置，而不是放大圆孔；
5. 若热熔螺母太紧/太松，只调整 `INSERT_PILOT_D`，每次约 `0.10 mm`；
6. 复核 M3 螺丝长度和左右壳连接螺丝长度；
7. 最后再根据实际线材确认进线孔、理线槽和装配顺序。

## 11. 给下一位 AI 的工作原则

- 不要覆盖或重命名 V2；所有新修改放在 `hardware/scanner-gun-v3` 或更高版本目录；
- 不要重新添加摄像头/按钮模拟实体，除非用户明确要求；
- 不要把摄像头圆孔误认为按钮开口；
- 不要重新加入 V2 的面板下方圆柱 boss；
- 不要自动生成测试片，用户已经明确不需要；
- 对“稍微大一点”“下层”“同样”等自然语言必须先写出明确尺寸和几何解释，并在回复中告诉用户；
- 任何新增开口、孔位、支架凸台都要有实物尺寸或明确用途；
- 先验证 B-Rep 有效性，再生成 STL/3MF；
- STEP 是当前首选的 Fusion 可编辑交付格式，`.f3d` 只能在 Fusion 内可靠生成；
- 若 Fusion 被锁屏、弹窗或登录状态阻塞，不要绕过系统锁屏，应告知用户解锁后继续；
- 保持结构精简、左右对称、可打印、可装配，避免装饰性特征和未确认的硬件。
